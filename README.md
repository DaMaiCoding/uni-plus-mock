# 🦈 uni-plus-mock

## 👋 项目简介

基于 `nestjs` 开发的 `mock` 数据后端服务

为 `uni-plus` 提供 `mock` 数据进行测试，无需安装 `mysql` 等环境

## 🍇 依赖安装

```bash
pnpm i
```

## 🍕 运行使用

```bash
pnpm start:dev
```
